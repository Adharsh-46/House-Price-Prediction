HOUSE PRICE PREDICTION WEB APP
==============================

ABOUT THE PROJECT
-----------------
House Price Prediction is a web application created as a Minor Project to estimate a property's value. By analyzing various features such as location, total area in square feet, rate per square foot, and the type of the house, the application utilizes a Machine Learning Linear Regression algorithm to provide estimated price forecasts.

FEATURES
--------
* User Authentication: Secure login system to access the prediction features.
* Intuitive UI: Simple, clean, and user-friendly interface for seamless navigation.
* Accurate Predictions: Core logic powered by a pre-trained Linear Regression model.
* Instant Results: Enter property details and get real-time price estimations.

TECHNOLOGY STACK
----------------
* Frontend: HTML, CSS (Simple User Interface)
* Authentication: PHP & HTML (Login systems)
* Backend & Core Logic: Python, Flask (Deployment and execution API)
* Machine Learning: Scikit-learn (Pre-trained ML model loading and interface)

PROJECT TYPE
------------
Minor Project
